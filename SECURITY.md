# Security

These scripts hold no secrets: they read your API token from the environment.

**Found a vulnerability in InfraNest itself?** Please report it privately, not in a public issue: see
[infranest.io/security](https://infranest.io/security) and
[security.txt](https://infranest.io/.well-known/security.txt).

**Found a script that could leak a token or change more than it says?** Open an issue, or for anything sensitive,
use the address in security.txt.
